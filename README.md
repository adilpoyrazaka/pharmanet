# MEDPUSULA

MEDPUSULA helps someone with private health insurance find a pharmacy near
them that is affiliated with their specific insurer, instead of manually
checking each insurance company's site or calling around.

## Current state

This is a Next.js scaffold running on demo data. No real pharmacy or
insurance affiliation data is connected yet.

## Getting started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

## Testing

```bash
npm test        # Vitest logic tests
npm run test:e2e  # builds the app, then runs Playwright end-to-end tests
```

Node 22 is required (see `.nvmrc`).
